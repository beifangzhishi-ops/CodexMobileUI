# Codex Web 工作台（视觉原型）

`web/` 是独立于 Android/Expo 的 React、TypeScript、Vite 网页项目。

## 现状（2026-11-12）

- 桌面端 ChatGPT 风格侧边栏（推挤动画）、移动端抽屉、亮暗主题、聊天页、搜索、项目与电脑筛选。
- 示例电脑 6v、noha，以及演示对话、运行状态和执行记录全部是**虚构的界面数据**，并非实时连接检测。
- 发送消息只修改浏览器当前页面的内存状态，并显示“未连接 App Server”提示；附件只显示文件名，不读取或上传文件内容。
- 未实现真实 App Server 连接、身份认证、模型执行、审批、设备发现、文件操作或 Tailscale 部署。
- 开发与预览服务只监听 `127.0.0.1`，在接入认证网关之前不得向公网发布。

## 命令对应的 npm 脚本

| 脚本 | 作用 |
| --- | --- |
| `dev` | 在本机 `http://127.0.0.1:4173/` 运行开发预览 |
| `check` | TypeScript 静态检查 |
| `build` | TypeScript 检查并生成 `dist/` 静态产物 |
| `preview` | 在本机 `http://127.0.0.1:4174/` 预览产物 |

依赖锁文件由 `web/package-lock.json` 管理。安装时将 npm 缓存指定在被 Git 忽略的项目根目录 `.npm-cache/` 中，避免使用全局受限缓存。

## 后续连接边界

浏览器只应通过 HTTPS/WSS 连接经过身份认证的统一 Web 网关，由它通过 Tailscale 内网连接各电脑的受保护 Gateway。原生 App Server 的 `127.0.0.1:45891` 不暴露给浏览器，各机器独立的 `CODEX_HOME` 与线程数据不合并。
